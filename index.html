Cấu hình GitHub Gist

Tạo tại github.com/settings/tokens → chọn scope gist.

Gist ID là chuỗi dài trong URL: gist.github.com/<user>/GIST_ID

📖

Hướng dẫn sử dụng nhiều thiết bị

  1. Tạo token: Vào GitHub Settings → Tokens, bấm Generate new token (classic), chọn scope gist, sao chép token.
  2. Thiết bị đầu tiên: Dán token vào ô trên → bấm ✨ Tạo Gist mới → Gist ID tự điền → bấm 💾 Lưu cài đặt.
  3. Thiết bị khác: Mở app, vào tab ⚙️ Cài đặt, dán cùng token và cùng Gist ID → bấm 💾 Lưu cài đặt. Dữ liệu sẽ tự tải về.
  4. Tự động đồng bộ: Mỗi khi bạn chuyển về tab trình duyệt sau khi dùng thiết bị khác, app sẽ tự pull dữ liệu mới nhất. Chiến lược Last-write-wins — thiết bị nào ghi sau thắng.
🔒 Bảo mật: Token được lưu trong localStorage của trình duyệt. Không dùng trên máy tính công cộng hoặc chia sẻ thiết bị với người khác khi đã lưu token.
